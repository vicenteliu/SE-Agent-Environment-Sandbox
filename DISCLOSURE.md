# Disclosure

What this repository deliberately does not contain, and why. Published as an artifact
rather than kept as a checklist, because a checklist is skipped under deadline and a
missing file is not.

## Not here, on purpose

**No employer and no client is named.** Not the organisations whose estates taught the author the
🔨 rows, and not the party whose specification informed the shape of this chain. Where scale
matters to an argument it appears as scale — *"a large quantised model on one machine"* — never as
a place or a party.

**No specification text.** The role that prompted this repository had a written specification.
None of its sentences are here. The chain is derived from what the work *is*, in the author's own
words; a distinctive phrase from a job description reproduced in a public repository identifies
the description.

**No claim of scale.** Every run in this repository happened on one machine in one lab tier. The
words *distributed* and *at scale* appear only in specifications marked 🧭 or ⛔, and in this
sentence; *production* appears in the footing table only where it describes the author's prior
operating work under a 🔨 marker, never a run made here.

**No cloud.** The chain is on-prem by design and by honesty: the author does not operate cloud
platforms for a living and this repository does not pretend otherwise.

**No rehearsal material.** The private half of this work includes spoken-delivery acceptance and
its recordings. None of it is here and none of it will be.

## The test that was applied

Not *"is this detail sensitive"* but **"does this detail, added to the others already on the
page, narrow the field?"** Specificity identifies where vocabulary does not. A figure that is safe
alone can stop being safe next to two others.

Keyword scanning is not a substitute for that question and was not used as one.

## Where the line actually sits

| Publishable | Stays private |
|---|---|
| The chain, hop by hop, and what breaks at each | Any environment it was learned in |
| Selection criteria between isolation tiers | Which tier a given organisation runs, and why |
| The lab tiers and their boundaries | Anything a party would recognise as theirs |
| Marker-bounded capability — *"🔨 virtualisation with GPU passthrough"* | The lab's owner, size, purpose, and the org around it |
| Measurements from this repository's own runs | Any number from anywhere else |

## Direction of flow

Material moves **one way**: a finished artifact is de-identified and published outward. This
repository never imports from a private workspace, never cites a private file as evidence, and
every claim it makes stands on its own in publishable terms. The mapping of which private fact
became which published sentence is itself private — putting it here would undo the work it records.
